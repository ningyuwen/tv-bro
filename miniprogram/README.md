### 持续发现与断线恢复

- 小程序在前台未发现电视或意外断线后持续寻找，重试等待时间依次为 **3、6、12、15 秒**，之后上限保持 15 秒。每轮广播发现约 4 秒，连接尝试还会增加耗时，因此等待间隔不是整轮发现或重连的总时长。
- 优先尝试上次保存的地址和授权；盒子 IP 改变时，广播发现通过稳定的 `deviceId` 找回同一设备并使用原授权。多台盒子会显示选择列表。
- 本次页面使用期间，同一设备自动发起授权请求最多一次。电视拒绝或授权超时后，需要用户点选设备再次请求，自动发现不会反复触发电视授权弹窗。授权成功后重试间隔复位。
- 小程序退到后台或用户手动断开时，停止自动发现与重连。需要时可点「重新寻找电视」继续，不重放断线前的操作。

### 触控速度与网页滚动方向

触控设置位于触控板下方。指针速度和网页滚动速度分别可设为 **50%–200%**，每档 **25%**，默认均为 **100%**；「反向网页滚动」默认关闭。三项设置保存到手机本地的 `lime-touch-preferences-v1`，重新打开小程序后恢复。速度和反向设置仅作用于网页指针及网页滚动，菜单或弹窗的焦点导航保持原方向和速度。

### 分用途输入与反馈

- 「网址 / 搜索」在电视当前标签页打开网址，或使用电视浏览器配置的搜索引擎搜索；「电视输入框」向电视当前选中的网页或浏览器原生输入框发送文字。
- 两种用途分别使用 `openText`、`pageText` 草稿，切换用途或短暂退到后台可在内存中保留；草稿不写本地存储，退出页面或小程序进程结束后消失。可用「清空」清除当前用途的草稿。
- 发送过程中显示进度，完成后显示成功或失败结果，并防止重复发送。未选中输入框时（`no_input`），提示先在电视选中网页或原生输入框。
- 用途切换、断线等状态变化后隔离旧请求的返回结果，避免旧响应覆盖当前输入提示。

### 设备更换与重新授权回归（2026-10-11）

基于 master `873be6a3d6bafbef72480345bb4a05fa7f5a7e0a`，新增 [`tests/reauthorization.test.js`](tests/reauthorization.test.js) 的 26 项回归测试。复用 `node:test`、`node:assert/strict` 和已有 VM 加载方式，不增加依赖。测试辅助代码在 [`tests/helpers/authorization.js`](tests/helpers/authorization.js)：运行真实的 `remote.js` 页面、`Discovery`、`readSession` 和 `RemoteClient`，在微信 TCP/UDP、存储与时钟边界提供模拟响应，断言 NDJSON 请求中的实际 token、缓存、页面状态及资源释放。所有设备标识、地址和凭证均为测试数据，不发送真实网络请求。

| 场景 | 自动化断言 |
| --- | --- |
| 旧包授权缓存、同 IP 新 deviceId | 旧地址只查询无凭证的 info；身份不符后广播发现新设备，重新授权前不发送旧 token |
| 旧地址不可达、设备地址或端口变化 | 通过广播发现恢复连接；仅相同 deviceId 可在 TCP 身份确认后复用旧授权 |
| 多台设备、损坏的授权缓存 | 优先选择已记住的身份；多个陌生设备等待用户选择；无效缓存不用于连接 |
| UDP 与 TCP 身份不一致 | 停止连接，不发送授权或带凭证的状态请求 |
| 首次授权成功 | 电视确认前保持未连接；确认后保存新 token，状态验证后连接，重开及控制命令使用新 token |
| 旧 token 返回 unauthorized | 清除模拟存储中的失效授权及客户端 token，新的 authorize 请求不携带旧凭证 |
| 拒绝、繁忙、超时、无效授权响应 | 不标记已连接、不写入无效凭证、不自动重复授权；明确重试可恢复 |
| 授权成功后状态请求断线 | 保留已获得的新授权，下次连接复用它；普通网络失败不误删有效缓存 |
| 页面退出、连接切换、迟到响应 | 取消旧连接；旧授权响应不能覆盖新会话，旧 unauthorized 响应不能删除新会话缓存 |

针对用例复现的问题做了三类小范围修复：失效 token 在重新授权前清空；授权阶段失败后保留错误并停止本轮自动发现/重试；异步连接与授权结果在处理前检查页面可见性及连接代次，避免旧连接修改当前会话。

## 机顶盒音量

遥控面板的「机顶盒音量」位于视频进度下方，提供 0–100% 音量滑块和静音开关。滑动时预览百分比，松手提交一次；静音开关发送明确的静音/取消静音状态。约每秒读取盒子实际媒体音量，因此电视遥控器修改音量后也会同步。音量按盒子实际档位取整；断线、离开小程序时取消拖动，不重放旧命令。
