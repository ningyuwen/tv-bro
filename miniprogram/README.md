# 青柠遥控小程序

AppID：`wx50081aa2c2078871`。在微信开发者工具中导入本目录，使用管理员或已添加的开发者微信扫码登录，点击「预览」在手机体验。游客模式只能用于开发界面，不代表手机真机已验证。

1. 在盒子安装并打开青柠浏览器，手机连接和盒子相同的 Wi-Fi。
2. 打开小程序自动发现盒子。首次在电视弹窗选择「允许并记住」，以后小程序自动连接；多台盒子会显示列表。发现失败可手动输入盒子地址，不填配对码时也通过电视确认授权。二维码是备用方式。
3. 单指移动指针，轻点点击，双指滚动。输入网址或搜索词点「打开 / 搜索」；点中网页输入框后可「输入到网页」。
   触控板高度为可用屏幕的 58%（640–1040rpx 范围）。
   触控板下方快捷操作区包含返回、首页、刷新、菜单、切换标签、播放 / 暂停、新标签和关闭标签；已移除底部指针微调和前进入口。
4. 手机或浏览器离开前台即断开，授权保留。浏览器和小程序再次打开可自动重连，不重放旧操作。电视「设置 → 手机遥控 → 关闭手机控制」可关闭发现并清除授权。

二维码是本地连接参数，需在此小程序内扫描；直接用微信首页扫一扫不会自动打开此小程序。每个配对码只能使用一次、五分钟有效。再次开启配对将撤销旧手机的授权。无服务器、无云端账号、无需 AppSecret。没有公网控制能力。

TCP 使用 `wx.createTCPSocket`，TCP 基础库至少 2.18.0；UDP 广播发现需 2.24.0（`setBroadcast`），官方说明见：https://developers.weixin.qq.com/miniprogram/dev/api/network/tcp/wx.createTCPSocket.html 。项目使用 3.10.0，可在开发者工具中选择已安装的更新版本。无需关闭合法域名校验；此项目使用局域网 TCP，不使用 wx.request。iOS 若拒绝本地网络访问，请在系统设置为微信开启本地网络权限。访客 Wi-Fi、AP 隔离或不同子网可能阻断连接；配对时可在电视显示的其他地址中选择网线地址。

2026-10-09：小程序 0.1.2 已通过开发者工具上传，用户确认后台已设为体验版；电视端 0.1.2 已覆盖安装。普通和隐私模式的真机 WebView 视频定位、前后 10 秒和播放/暂停均已验证，原手机授权保留。退出并重新打开手机体验版即可加载更新；手机拖动手感与具体视频网站兼容性待实际使用确认。

更新电视浏览器和小程序后，连接页面会显示「视频进度」面板：后退 / 快进 10 秒、播放 / 暂停、当前时间 / 总时长，以及松手跳转的进度条。状态约每秒更新，切换视频、标签或断线后取消未完成的拖动，不重放指令。连接旧版浏览器时会提示更新电视端。

隐私模式同样使用这套控制接口，进度状态不包含视频地址或网页标题，不新增播放记录保存；切换隐私模式后需要重新连接。直播、视频未加载或播放器不支持定位时进度条不可用；WebView 中跨域 iframe 和封闭 Shadow DOM 需要额外适配。

新增控制已通过自动测试及微信开发者工具编译，电视安装、体验版上传及普通/隐私模式的本地视频验收已完成。具体视频网站兼容性待实际使用确认。
